# WaveParticle Mobile

A mobile-first web app where you do a real task while a historical character lives a parallel story, one focus step at a time. The first character is J. Robert Oppenheimer.

Status: repository structure and a minimal Next.js app are in place. Features are built from `docs/USER_STORIES.md`, one GitHub issue at a time.

## Quick start
```bash
nvm use && npm ci
npm run dev
npm test
```
Configuration: copy `.env.example` to `.env` and fill in values (never commit `.env`).
Live URL: TODO(human): not deployed yet.

Stack: Next.js (App Router) · React · TypeScript · Tailwind CSS · Supabase (planned) · Vercel (planned). Versions: [docs/TECH_STACK.md](docs/TECH_STACK.md).
