# WaveParticle Mobile

Mobile-first web app (PWA) for WaveParticle: pick a character, set a goal, and the character helps you start and finish it, one focus session at a time.

Status: Sprint 0 — repository setup. Product requirements will live in `docs/PRD.md`; the agent rules in `AGENTS.md`.

Planned stack: Next.js (PWA) · TypeScript · Supabase (auth, Postgres) · Vercel.
