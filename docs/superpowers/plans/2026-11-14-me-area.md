# The Me area Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ME, ME-CAL, SIG, ME-REC and the Story record as signed-in screens from the account, matching prototype v4.

**Architecture:** Server pages read `createSupabaseProgressStore` and `profiles`; pure functions in `src/lib/me/` shape every screen; small client components hold the disclosure, calendar, segmented control and toggles; server actions save the display name and the clock setting through the user's own client.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript 6, Supabase, Vitest (`renderToStaticMarkup`), Playwright.

**Spec:** `docs/superpowers/specs/2026-11-14-me-area-design.md`

## Global Constraints
- Tokens only; controls follow DESIGN.md section 6. No counts, totals, streaks, heat shading or crosses.
- Do not change Home, the Goals pages, Life Path rows, the goal dialogue, focus, rest or summary; no model calls or content.
- `src/app/me/page.tsx` keeps `<h1` and `app-screen` (existing file checks); Sign out stays on `/me`.
- No new issues; extras go to "Left for later" in the PR.

## Review Focus
1. A session with Steps opened but none done never appears in history or opens a record. Test in Task 1.
2. A session id of another account, or a session that is not completed, gives no Story record (404 page, no data). Test in Task 1 and Task 5.
3. Device storage blocked (private mode): Appearance and Signals still render with defaults and do not throw. Test in Task 2.
4. Notification permission refused: the Lock-screen row stays Off with a visible reason. Test in Task 4.
5. A display name that is empty, only spaces or longer than 60 characters is refused with words, and the typed text is kept. Test in Task 2.
