# Tokens v7 Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make `src/app/tokens.css` and base styles match DESIGN.md version 7 (issue #170).

**Architecture:** Rename and add tokens in `tokens.css` (the only file allowed to hold hex values); derive `--tint` and `--gray` with `color-mix` over `--bg`; add capsule button classes to `globals.css` that use only tokens. Tests in `tests/design-tokens.test.ts` change first.

**Tech Stack:** CSS custom properties, Tailwind 4 `@theme inline`, Vitest.

**Spec:** DESIGN.md sections 3.1 to 3.4, 3.8, 3.9, 3.11, 6.1 (not edited).

## Global Constraints

- DESIGN.md is not touched. Contrast values in DESIGN.md are unchanged; tests check them.
- Light `--control #426F4C`, `--on-control #FFFFFF`, `--accent-text #37613F`, `--mark #62906B`, `--fill-soft #C3E0C8`; `--tint` = `--control` 14% over `--bg`; `--gray` = `#3C3A37` 12% over `--bg`.
- Dark and `.skin-opp` (and the `prefers-color-scheme` block): `--control #A1CAA8`, `--on-control #050B06`, `--accent-text #A1CAA8`, `--mark #719F7A`, `--fill-soft #2C4A33`; `--tint` 18%; `--gray` = `#EBEBF5` 14% over `--bg`.
- Removed: `--accent`, `--fill`, `--on-fill`, `--fill-border`, `--shadow-tag`, `--r-control`. Added: `--r-field: 0.875rem`, `--r-capsule: 999px`.
- No hex or `rgb()` outside `tokens.css`.

## Review Focus

- The `prefers-color-scheme` block drifts from `.theme-dark`: test that both define identical v7 tokens.
- `.skin-opp` forgets `--tint`/`--gray`/`--fill-soft` and inherits light values: test each theme block defines them.
- Old names linger in `src/`: test that no file under `src/` references a removed token.
- Tailwind `--color-accent` still points at the removed token: test that it maps to `--control`.
- A button style gets a bottom-edge shadow back: test that button CSS has no `--shadow-tag` and no 2px offset.
