# Data
Where data lives and what fields mean. For large files write the path, never paste the content.

| Dataset / store | Location | Fields | Notes |
|---|---|---|---|
| Story content (Companions, stories, model inputs) | Supabase Postgres, `supabase/migrations/20261119000000_story_content.sql` | companions; stories (title, period, goal sentence, Who I am, opening); story inputs (date, facts, forbidden terms, key moments, stage 0 inputs) | Read by the app through `getStoryContent()` (#284). Seed: the files below and `src/content/companions.json`, `src/content/oppenheimer/periods.json`, loaded by `scripts/content/import.mjs` and written back by `scripts/content/export.mjs`. Key moments are stored unconfirmed (KEY-UNCONFIRMED) |
| Story cards and part titles (26 Oppenheimer stories) | Supabase Postgres, `supabase/migrations/20261120000000_story_cards.sql` | story cards (key, version, story, kind, part, slice, order, text, published) and part titles | Seed `src/content/oppenheimer/story-decks.json` (copy of the prototype deck of 2026-11-12, AI-written, unreviewed), loaded as version 1, published, by `scripts/story-cards/import.mjs` (#293). Read only by content editors on ADM-06; the phone does not read them yet |
| Oppenheimer story database (26 stories, facts) | `src/content/oppenheimer/stories.json` (seed of the story content tables) | story id, sequence, title, date, goal, facts, forbidden terms, key slices, provenance | Imported from the planning database; the source entry paths and the key-slice derivation are recorded per story. Each key line is one first-person past-tense sentence of at most 18 words |
| Oppenheimer story database source | `2_Areas/Product/oppenheimer-stories/en/database/` in the planning folder (outside this repo) | story id, era, date, goal, tasks, happened, knowledge | Source of the facts the AI writes cards from |
| Oppenheimer story order and leak map | `1_Projects/Newfeatures/NF3_content/story_openers_2026-10-29.json` in the planning folder (outside this repo) | sequence, story id, title, dialogue opener, forbidden terms | Canonical chapter order and terms that must not leak into generated story text |
| Authored fallback cards | `1_Projects/Newfeatures/NF3_content/` in the planning folder (outside this repo) | cards for two stories ("finding the place", the Trinity night) | Used when generation fails |
| Account progress | Supabase Postgres, `supabase/migrations/20261106120000_save_server_progress.sql` | session companion and story, session steps, shown lines | Loaded by Home, Goals and the Life Path for the signed-in account |
| Model gateway settings | Server environment, names in `.env.example` | `MODEL_API_KEY`, `MODEL_API_URL`, `MODEL_NAME` | Read only by `src/lib/model-gateway/server.ts`. Missing values use an authored line. The benchmark keys are separate and are not read here |
