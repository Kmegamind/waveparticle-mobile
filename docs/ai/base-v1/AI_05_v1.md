## 1. Purpose

Stop two things: (a) a person in real distress writing a goal, a step, a note or a chat message that then becomes a title, a split, a line, or model input, and (b) a model reply that could harm. When it fires, the person gets an out-of-character page (S1), not his voice. He never knows and never mentions it.

## 4. Method (hypothesis)

Two layers, both on the server for every position:

1. **Keyword and phrase layer (code)**: explicit self-harm or suicide intent, intent to harm others. Separate lists for English and Chinese (NF6: "emotion rules once failed silently in Chinese"). Runs always, no model, no cost.
2. **Small classifier call (model)**: only for text that is long enough or contains a near-miss word; output is one word. Prompt text (hypothesis):

```
ROLE
You check one short text written by a person using a focus app. You do not reply to the person.

INPUT
# The text
{{text}}

QUESTION
Does the text show a clear, current intention to seriously hurt themselves or someone else? Ordinary stress, tiredness, frustration, dark humour and figures of speech such as "this deadline is killing me" do NOT count.

OUTPUT
Reply with exactly one word: strong or none.
```

Rule: **strong** fires S1. Everything else passes. NF6 draft: "strong signals only. Ordinary task stress does not."

Output guard on model replies: the AI-6 rules plus a small denylist for method or instruction content (hypothesis; the list belongs to compliance). A hit uses the AI-6 fallback line, **not** S1 (S1 is for the user's words).

## 5. Output

S1 event with `position` only. No raw text is logged or stored (NF6: "position only, no raw text"; privacy decision marked Yue's). The flagged text is not used as a mission, step, note or chat context; the input is emptied on return.

## 6. Guardrails on the hook itself

- Fires on **strong** signals only; always has "Back to my task"; no second confirmation, no counter, no quote of what they wrote, no diagnosis, no repeated "are you OK?" (NF6 "Not here").
- System voice (Shell), not his: no name, face, slip or tape.
- Two test sets, English and Chinese, built with compliance before launch (NF6).
- Classifier must not receive anything but `text` (no character, no story, no history).

## 7. Fallback

| Failure | Behaviour |
|---|---|
| Classifier down or slow (> 1.5 s, hypothesis) | Keyword layer alone decides. **The text is still not sent to AI-1 or AI-4 if the keyword layer flags it.** If the whole stack is down, the product is already unable to call models, so the text is not sent anywhere |
| Support resources not yet configured | S1 shows the placeholder text from NF6 until legal sets the region list. **Known compliance gap in the main PRD** |
| False positive | "Back to my task"; no penalty; add the phrase to the near-miss set in the test sets |

## 8. Latency and cost

Keyword layer: negligible. Classifier: small model, ≈ 120 input tokens, 1 output; runs only when needed; budget ≤ 1 s so it does not add to the 1a call at GD2 (run them in parallel, hypothesis). C1 adds one classifier call before each reply call unless the keyword layer is enough.
