# Admin area

`/admin` (#287, ADMIN, `docs/decisions/0016`): the content admin shell (product name and "Content admin", the menu with Companions ADM-03 (#309), Stories ADM-06 (#293), App text ADM-07 (#288), Hotlines ADM-14 (#118, admin role only), Prompts ADM-08 (#308, group "AI rules") and Publish history ADM-12 (#289), and Sign out). A desktop tool that looks like the admin prototype (#313, ADMIN-DESKTOP): the `--adm-*` tokens in `src/app/tokens.css`, a minimum width of 1024 px with the menu always a left rail, tables inside panels (Companions, App text, Publish history), state pills, id chips and breadcrumbs (`src/app/admin/admin-ui.tsx`); no phone layout and no 44 px tap size. Publish history names each row (`src/lib/admin/history-names.ts`) and shows the date as `MM-DD HH:mm` UTC; the Companions table's Shown to users and Last change come from `src/lib/admin/companion-rows.ts`. It opens only for an account whose `public.content_role()` is `admin` or `writer`; the proxy answers every `/admin` path with the normal 404 otherwise, signed in or not, and the admin layout checks again on the server. No service-role key

Path: `src/app/admin/`, `src/lib/admin/roles.ts`, `supabase/migrations/20261116000000_content_roles.sql`
