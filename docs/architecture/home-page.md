# Home page

Signed-in Home from the account only (#268, prototype v4). `homeView` picks one state: HOME-0 (the account never started a Goal), HOME-1 (the most recently active Goal in progress: title, Companion, where you left it, his newest shown card, #69's Continue, Start something else, the ⋯ Goal options sheet, My Companions, In progress) or HOME-NONE (portrait, his carried line from the last summary, New session, Quick Replay chips that open `/goal?line=` with the Goal's title, #271). HOME-3 (#87): the same Goal after more than three days since its last activity on the account, as a system card "Welcome back" with Pick it back up (Continue) and Start over; Start over opens HOME-3B, and Start from Step 1 (`startOverAction`, `src/lib/home/start-over.ts`) marks the open session `restarted` and opens `/focus?goal=`, which starts a new session at Step 1 with the current story from its start (T5). Put on hold and Mark done (`setGoalStatusAction`) change the Goal and park its open session as `on_hold`, with a 5 second Undo toast. Links to `/goal` and `/focus` show in every environment (#278)
