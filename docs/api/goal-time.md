# src/lib/prototype/goal-time.ts

`src/lib/prototype/goal-time.ts`: `parseTypedTime(text)` (5 to 300 minutes, rounded to 15, otherwise `null`), `findTimeInGoal(goal)` (GOAL-TIME; whole minutes as written, NO-ROUNDING; a duration that describes the thing, such as "a 2 hour lecture", is skipped), `removeTimePhrase(goal)` (the goal without its time phrase, for the Goal title), `formatMinutes(minutes)` and `TIME_HINT`.
