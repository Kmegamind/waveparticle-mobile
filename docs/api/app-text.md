# src/lib/app-text/

`src/lib/app-text/` (#288, `docs/decisions/0017`): `catalog.ts` (browser-safe) has `APP_TEXT_KEYS`, `AppTextKey`, `AppTexts` (`Record<AppTextKey, string>`), `APP_TEXT_DEFAULTS` (from `src/content/app-text.json`, the one source of the defaults), `isAppTextKey(value)` and `screenOf(key)`. `repository.ts` (server only): `getAppTexts()` returns the text to show for every key (the published row of `public.app_text`, or the code default when there is none or the read fails), kept at most 60 seconds (`APP_TEXT_CACHE_MS`); `clearAppTextCache()`; `createAppTextRepository({ readRows, cacheMs?, now?, log? })` and `readPublishedAppText()` (public key, no session). The log line is `{"source":"app_text","event":"app_text_read_failed"}` with no text. `provider.tsx` (client): `AppTextProvider({ texts })` and `useAppText(key)`, which answers the default without a provider. `admin.ts` (server): `appTextAdminRows(rows)` builds the ADM-07 list and `writeAppText(write, deps)` runs one save, publish or roll back after checking the user, the role, the key and the text; `src/app/admin/app-text/actions.ts` has the server actions `saveAppTextDraftAction(key, body)`, `publishAppTextAction(key, version)` and `rollBackAppTextAction(key, version)`, each returning `{ ok: true, version? }` or `{ ok: false, error }`.
