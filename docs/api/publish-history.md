# Publish history

Publish history (#289, `docs/decisions/0018`, `supabase/migrations/20261118000000_publish_history.sql`): `private.set_published_app_text` now inserts one `public.publish_history` row (`kind` `'app_text'`, `item_key`, `version`, `action` `'publish'` or `'roll_back'`, `acted_by` = `auth.uid()`, `acted_at`) in the same transaction, and roll back accepts any version published before that is not published now. `public.list_publish_history(row_limit integer default 100)` returns `(id, kind, item_key, version, action, acted_by, acted_by_email, acted_at, is_current)` newest first (limit 1 to 500) to `authenticated` callers with a content role (`42501` otherwise). `src/lib/publish-history/admin.ts` (server): `readPublishHistory(rpc)`, `publishHistoryEntries(rows)` (the ADM-12 rows: kind label, key, version, Published or Rolled back, person, UTC time, `canRollBack`) and `rollBackHistoryItem(item, handlers)`; `src/app/admin/publish-history/actions.ts` has `rollBackFromHistoryAction(kind, key, version)`, which runs `rollBackAppTextAction` for `app_text`.
