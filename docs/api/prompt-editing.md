# Prompt editing

Prompt editing (#308, `docs/decisions/0025`, `supabase/migrations/20261125000000_prompt_editing.sql`): `public.list_prompt_versions()` returns `(key, version, active, body, params, note, created_at, activated_at)` to content editors (`42501` otherwise); `public.save_prompt_draft(prompt_key text, prompt_body text, prompt_params jsonb, prompt_note text) returns integer` (editors; a new inactive version `max + 1`; `P0002` for an unknown key, `22023` when the settings are not an object); `public.publish_prompt(prompt_key text, prompt_version integer)` and `public.roll_back_prompt(prompt_key text, prompt_version integer)` (admin only), both through `private.set_active_prompt`, which calls `public.activate_prompt` and inserts a `publish_history` row of kind `'prompt'`. In the app: `promptRowProblems(row)` from `@/lib/model-gateway` (the gateway's own row check, `string[]`, empty when usable); `src/lib/prompts/admin.ts` has `promptList(rows)`, `promptDetail(key, rows)`, `settingsLines(params)`, `parseSettings(text)`, `readPromptVersions(rpc)` and `writePrompt(write, deps)`; `src/lib/prompts/diff.ts` has `lineDiff(before, after)` and `settingsText(params)`; `src/app/admin/prompts/actions.ts` has `savePromptDraftAction(key, body, settings, note)`, `publishPromptAction(key, version)` and `rollBackPromptAction(key, version)`.
