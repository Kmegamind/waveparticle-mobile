# src/lib/research/condition.ts

`src/lib/research/condition.ts` (server only, #114, `docs/decisions/0031`): `readResearchCondition(client)` returns `"no_story"` or `null` from `public.research_condition()` through the user's own client; a missing function (`PGRST202`, `42883`: the migration has not run) is `null`, any other error throws, so the focus page never falls back to the Story. `storyIsOff(client)` is `true` for `"no_story"`. The database side is `supabase/migrations/20261129000000_research_conditions.sql`: `public.research_conditions` (closed to the API) and `public.research_condition() returns text` (`security definer`, `auth.uid()` only, executable by `authenticated`). `src/lib/progress/focus-session.ts` adds `NO_STORY` (`"none"`, the `companion_id` and `story_id` of a Story-off session), `isStoryOff(session)`, `planStorageKey(plan)`, `AccountFocusPlan.storyOff` and the `storyOff` option of `openFocusSession`; `src/lib/prototype/session.ts` adds `NO_CARDS` (`StepCards.none`) and `returnWithoutPopup(session, nowMs)`.
