# src/lib/research/condition.ts

`src/lib/research/condition.ts` (server only, #114, `docs/decisions/0031`): `readResearchCondition(client)` returns `"no_story"` or `null` from `public.research_condition()` through the user's own client; a missing function (`PGRST202`, `42883`) is `null` with one warning per process unless `RESEARCH_STUDY_ACTIVE` is `1` (`studyIsActive(env)`), when it throws like any other error, so the focus page never falls back to the Story. Both log under the feature `research`. `storyIsOff(client)` is `true` for `"no_story"`. The database side is `supabase/migrations/20261129000000_research_conditions.sql`: `public.research_conditions` (closed to the API) and `public.research_condition() returns text` (`security definer`, `auth.uid()` only, executable by `authenticated`), and `sessions.story_off_at timestamptz`. `src/lib/progress/focus-session.ts` adds `isStoryOff(session)` (`sessions.story_off_at` is set; `ProgressSession.storyOffAt`), `doneWithStory(session, step)`, `planStorageKey(plan)`, `AccountFocusPlan.storyOff` and the `storyOff` option of `openFocusSession`; `src/lib/prototype/session.ts` adds `NO_CARDS` (`StepCards.none`) and `returnWithoutPopup(session, nowMs)`.
