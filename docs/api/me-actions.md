# src/app/me/actions.ts

`src/app/me/actions.ts` (#81, #71): `saveDisplayNameAction({ name })` returns `{ status: "ok", name }` (trimmed, 1 to 60 characters) or `{ status: "invalid" | "failed" }`; `setKeepClockRunningAction({ on })` (a boolean) returns `{ status: "ok" | "invalid" | "failed" }`. Both upsert the signed-in user's own `profiles` row (row-level security). `src/lib/me/me-view.ts`: `meView(progress)` gives `{ current, onHold, history }`; a history entry is a session with at least one done Step, its day is the first Done and its minutes are the Plan minutes of its done Steps. `src/lib/me/records.ts`: `sessionRecord(progress, id)` and `storyRecord(progress, id)` (only for a completed session). `src/lib/me/prefs.ts`: device settings under `waveparticle.prefs` with `readPrefs`, `writePrefs`, `applyPrefs` and `PREFS_SCRIPT`.
