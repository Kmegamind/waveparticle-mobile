# Help lines by region (#118)

`src/lib/safety/help-lines.ts` (browser-safe; SAFETY-REGION, SAFETY-REGION-STORE, SAFETY-DIRECTORY, HOTLINES): `DIRECTORY` (Find A Helpline, `https://findahelpline.com`), `US_LINE` (S1-0's labelled line), `COUNTRY_CODES` (the 249 ISO 3166-1 alpha-2 codes), `isCountryCode`, `countryName(code)` and `countryList()` (English names through `Intl.DisplayNames`, sorted), `contactIsValid` (phone or text: digits with an optional `+` and spaces; web: `https://`), `contactHref` (`tel:`, `sms:` or the address), `contactLabel`, `entryLine` ("Call or text 988" when the phone and text contacts share a number), `s1State(copy, { publicPage, session })` (`none` for no copy, no country, an unknown code, another account's copy, or a public page without a known matching session; `entry`; `no-entry`), `isPublicHelpPath`, `getKnownSession` and `setKnownSession` (the session this page load learned: a user id, null, or undefined while not known, for example offline), and the phone copy `{ userId, country, entry }` under `waveparticle.helpLine`: `readHelpLineCopy`, `writeHelpLineCopy` and `removeHelpLineCopy` (each never throws; writing and removing send the `waveparticle:help-line` event so an open S1 follows), `asCopy` and `asEntry` for untrusted JSON (a copy with no user id or a damaged entry is unreadable, so S1 shows S1-0).

`src/lib/hotlines/repository.ts` (server): `readPublishedEntry(client, country)`, `readAccountHelpLine(client, userId)` (the profile's `help_country` and its published entry; `ok: false` when the entry could not be read) and `readHotlineVersions(client)` (content editors: every version), through the user's own client. `src/lib/hotlines/admin.ts`: `hotlineList`, `hotlineVersions`, `newestDraft`, `checkIsDue` (older than `CHECK_DUE_MONTHS` = 6), `parseHotlineDraft` (problems in words) and `writeHotline(write, { userId, role, rpc })`, which refuses any role but `admin` before a call and then calls `save_hotline_draft`, `publish_hotline` or `roll_back_hotline` (`supabase/migrations/20261128000000_hotlines.sql`).

Routes and actions: `GET /me/help-line` (a public path) answers `{ signedIn: false }` only when there is no session: no session cookie, or `checkSession` (`src/lib/supabase/session.ts`) finds the session missing, invalid or expired, or the auth server answers 401 or 403. Any other auth error (a 5xx, a network failure, a transient refresh failure) answers `{ signedIn: true, ok: false }` with no user id, so the copy stays. Otherwise it answers `{ signedIn: true, userId, ok, copy }` (always 200, `no-store`; `ok` is false when the profile or the entry could not be read). `HelpLineSync` (`src/app/help-line-sync.tsx`, in the app shell outside `/auth`) calls it once per page load (10 s timeout): only `{ signedIn: false }`, a redirect to `/auth/sign-in` or another user's id removes the copy (another user's copy is replaced); a 5xx, a timeout, a network failure, a failed read, or a 200 that is not JSON keeps it unchanged (the last is logged with `logEvent`, feature `safety`). `HelpLineClear` on `/auth` removes the copy (sign out, account deletion, before a sign-in); a successful sign-in and Delete account remove it too. `/auth/callback` sets the one-time cookie `wp_help_line_reset` when it starts a new session; `consumeHelpLineReset` (first in `HelpLineSync` and `HelpLineClear`) then removes the copy and the cookie. The refresh's warnings (`help_line_not_json`, `help_line_unexpected_redirect`) are written with `logEvent` in the browser console only: there is no client-to-server log path. `readProfile` answers `ok: false` on a read error and falls back to the old columns only for a missing column (42703). `setHelpCountryAction({ country })` (`src/app/me/actions.ts`) saves a listed code or `null` to `profiles.help_country` (`setHelpCountry` in `src/lib/me/profile.ts`) and answers the new copy. `saveHotlineDraftAction`, `publishHotlineAction` and `rollBackHotlineAction` (`src/app/admin/hotlines/actions.ts`) run `writeHotline`; ADM-12 rolls a `hotline` row back through `rollBackHotlineAction`. Sign out removes the copy.
