# Help lines by region (#118)

`src/lib/safety/help-lines.ts` (browser-safe; SAFETY-REGION, SAFETY-REGION-STORE, SAFETY-DIRECTORY, HOTLINES): `DIRECTORY` (Find A Helpline, `https://findahelpline.com`), `US_LINE` (S1-0's labelled line), `COUNTRY_CODES` (the 249 ISO 3166-1 alpha-2 codes), `isCountryCode`, `countryName(code)` and `countryList()` (English names through `Intl.DisplayNames`, sorted), `contactIsValid` (phone or text: digits with an optional `+` and spaces; web: `https://`), `contactHref` (`tel:`, `sms:` or the address), `contactLabel`, `entryLine` ("Call or text 988" when the phone and text contacts share a number), `s1State(copy, { publicPage, session })` (`none` for no copy, no country, an unknown code, another account's copy, or a public page without a known matching session; `entry`; `no-entry`), `isPublicHelpPath`, `getKnownSession` and `setKnownSession` (the session this page load learned: a user id, null, or undefined while not known, for example offline), and the phone copy `{ userId, country, entry }` under `waveparticle.helpLine`: `readHelpLineCopy`, `writeHelpLineCopy` and `removeHelpLineCopy` (each never throws; writing and removing send the `waveparticle:help-line` event so an open S1 follows), `asCopy` and `asEntry` for untrusted JSON (a copy with no user id or a damaged entry is unreadable, so S1 shows S1-0).

`src/lib/hotlines/repository.ts` (server): `readPublishedEntry(client, country)`, `readAccountHelpLine(client, userId)` (the profile's `help_country` and its published entry; `ok: false` when the entry could not be read) and `readHotlineVersions(client)` (content editors: every version), through the user's own client. `src/lib/hotlines/admin.ts`: `hotlineList`, `hotlineVersions`, `newestDraft`, `checkIsDue` (older than `CHECK_DUE_MONTHS` = 6), `parseHotlineDraft` (problems in words) and `writeHotline(write, { userId, role, rpc })`, which refuses any role but `admin` before a call and then calls `save_hotline_draft`, `publish_hotline` or `roll_back_hotline` (`supabase/migrations/20261128000000_hotlines.sql`).

Routes and actions: `GET /me/help-line` (a public path that answers a signed-out request with `{ signedIn: false }` only) answers `{ signedIn: true, userId, ok, copy }` (always 200, `no-store`; `ok` is false when the profile or the entry could not be read). `HelpLineSync` (`src/app/help-line-sync.tsx`, in the app shell outside `/auth`) calls it once per page load: no session, a redirect or an answer that is not JSON removes the copy; another user's copy is removed first; a failed read or a network failure keeps it. `HelpLineClear` on `/auth` removes the copy (sign out, account deletion, before a sign-in); a successful sign-in and Delete account remove it too. `readProfile` answers `ok: false` on a read error and falls back to the old columns only for a missing column (42703). `setHelpCountryAction({ country })` (`src/app/me/actions.ts`) saves a listed code or `null` to `profiles.help_country` (`setHelpCountry` in `src/lib/me/profile.ts`) and answers the new copy. `saveHotlineDraftAction`, `publishHotlineAction` and `rollBackHotlineAction` (`src/app/admin/hotlines/actions.ts`) run `writeHotline`; ADM-12 rolls a `hotline` row back through `rollBackHotlineAction`. Sign out removes the copy.
