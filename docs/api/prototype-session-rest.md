# Rest and return in src/lib/prototype/session.ts

Rest and return in `src/lib/prototype/session.ts` (same key, still version 1; sessions stored before these fields load with the defaults): `startRest(session, now)` is Pause (freezes the clock, counts the Pause for the current Step in `pauses`, opens `rest = { pauseNumber, messages, draft, key }`, where `key` is a random UUID for this Pause, REST-ROUND-10, #518), `pauseNumberFor`, `addFirstRestMessage` (his first message always goes first), `hasFirstRestMessage`, `addRestMessage`, `withPauseKey` (gives a rest stored before #518 its `key`), `endRest` (R1-C10: `rest.ended = true`, an unanswered last message of the person dropped), `setRestDraft`, `backFromRest` (Back to step: rest ends, `returnPending = "rest"`), `leaveRest` (Home: the Step stays paused), `returnOnOpen(session, now)` (on opening the focus page with a frozen clock: an open rest counts as Back to step; away `AWAY_MS` = 5 minutes or more, divided by the test speed, sets `returnPending = "absence"`; otherwise the clock resumes), `setReturnLine` (stored once, never replaced), `startFromReturn` (Start: the pop-up closes and the clock continues from the frozen value). `pauseSession` records `pausedAtMs`, the first moment of the freeze.
