# src/app/goals/actions.ts

`src/app/goals/actions.ts` (#73, #78, #79): server actions, each returning `{ status: "ok" }` or `{ status: "failed" }` with no Goal text. `setGoalStatusAction(input)` is main's `setGoalStatus` unchanged (Put on hold, Mark done, Reopen as `in_progress`, and Undo). `resumeGoalAction({ goalId })` reopens the Goal's newest `on_hold` session and sets the Goal `in_progress` (it returns the same outcome as `setGoalStatus`). `renameGoalAction({ goalId, title })` trims the title, needs 1 to 1000 characters and returns `{ status: "crisis" }` without saving when the safety gate flags it. `setGoalKindAction({ goalId, kind })` takes `one_time` or `ongoing`. Rules in `src/lib/goals/goal-edits.ts`; the read in `src/lib/goals/goals-reader.ts` (`readGoalsData`, `isGoalId`); the views in `src/lib/goals/goals-view.ts` (`goalsLists`, `goalDetail`, `parseLine`, `parseTab`, `startHref`).
