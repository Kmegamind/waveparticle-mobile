# src/app/home-actions.ts

`src/app/home-actions.ts` (#268): server action `setGoalStatusAction({ goalId, status, sessionId? })` with `status` `on_hold`, `done` or `in_progress` (Undo). It returns `{ status: "ok", previous, parkedSessionId? }` or `{ status: "failed" }`. Rules in `src/lib/home/goal-status.ts` (`setGoalStatus`): a signed-in user, a UUID of their own Goal (row-level security), and one of the three statuses; `on_hold` and `done` also park the Goal's newest `open` session as `on_hold`, and `in_progress` reopens exactly the session given as `sessionId` (the `parkedSessionId` of the change being undone) when it belongs to that Goal, is still `on_hold`, and the Goal has no open session. `src/lib/home/home-view.ts`: pure `homeView(progress)` returns `{ kind: "first" }`, `{ kind: "goal", card, companions, inProgress }` or `{ kind: "none", carriedLine, replay, companions }`.
