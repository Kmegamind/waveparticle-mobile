# src/lib/content/companion-access.ts

`src/lib/content/companion-access.ts` (#521, `docs/decisions/0040`): who may play which Companion. `isPublicCompanion(c)` is true when `enterHref` is set. `canPreview(role)` is true for `"admin"` and `"writer"`. `contentForViewer(content, role)` returns every story for an admin or writer and only the public Companions' stories for anyone else (the Companions stay listed). `companionsForViewer(content, role)` gives the Companions list: a public Companion keeps his `enterHref`; for an admin or writer a Companion with stories and no `enterHref` gets `/companions/<id>` and `preview: true`; otherwise Enter is off. `playableCompanion(content, value)` is the Companion of `?companion=` (the default Companion when missing) when the content holds his stories, else `null`. `companionHref(id)`, `goalHrefFor(id)` (`/goal` for the default Companion, `/goal?companion=<id>` otherwise), `hasStories(content, id)` and `PREVIEW_NOTE`.

Related: `src/lib/content/repository.ts` has `getStoryContent()` (public Companions only), `getStoryContentForViewer(client)` (adds preview Companions for a content role; a failed role read is no role), `getFullStoryContent()` (admin code only) and `storyContentForRole(readContent, readRole)`. `src/lib/progress/viewer-session.ts` has `openViewerFocusSession(content, progress, goalId, { companionId, newId, storyOff?, now? })`, which opens or continues the session `/focus` and `/rest` work on and returns `null` when the Companion has no story in the viewer's content or the open session's story is not in it or not its Companion's, and `mayPlayPlan(content, plan)`. `premadeStepCards` takes `mayPlay(storyId)` and reads no deck for a story the account may not play.
