# src/lib/safety/crisis.ts

`src/lib/safety/crisis.ts`: `gateFreeText(text)` returns `{ action: "crisis-page", modelRequest: null }` when the keyword layer reports `crisis`, and `{ action: "continue" }` otherwise. The result never includes the text. `submitStepDraft` clears the draft on that path. `backToStep` returns an empty draft. The legal body text is a placeholder until the legal review (#121); the help for the chosen country comes from `docs/api/help-lines.md` (#118). It is the browser's keyword-only check; the server runs the classifier too (`docs/api/safety-classifier.md`, #117). `src/app/safety/crisis-page.tsx`: `CrisisPage({ onBack })` (S1) moves focus to its title (`#crisis-title`, `tabIndex={-1}`) when it mounts, so a screen reader announces it wherever S1 replaces a screen in place (the Step gate, Me, the rest page, the goal dialogue; #398). Since #118 it reads the phone copy (`readHelpLineCopy`) and shows S1-0, S1-E or S1-N (`data-s1` is `none`, `entry` or `no-entry`): S1-0 when no copy can be read, never a US default; on `/try` and offline it leaves out "Choose your country"; the directory is always a text link.
