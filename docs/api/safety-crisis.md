# src/lib/safety/crisis.ts

`src/lib/safety/crisis.ts`: `gateFreeText(text)` returns `{ action: "crisis-page", modelRequest: null }` when the keyword layer reports `crisis`, and `{ action: "continue" }` otherwise. The result never includes the text. `submitStepDraft` clears the draft on that path. `backToStep` returns an empty draft. Legal body text and the regional resource are placeholders until `docs/DECISIONS.md` or `docs/CONTENT_MODEL.md` states them. It is the browser's keyword-only check; the server runs the classifier too (`docs/api/safety-classifier.md`, #117). `src/app/safety/crisis-page.tsx`: `CrisisPage({ onBack })` (S1) moves focus to its title (`#crisis-title`, `tabIndex={-1}`) when it mounts, so a screen reader announces it wherever S1 replaces a screen in place (the Step gate, Me, the rest page, the goal dialogue; #398).
